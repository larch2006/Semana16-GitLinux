# Semana 16 - Git y GitHub en Linux

## Descripción
Este repositorio contiene las actividades prácticas de la Semana 16, desarrolladas en Ubuntu mediante una máquina virtual VirtualBox.

## Objetivo
Aprender a utilizar Git para controlar versiones y GitHub para almacenar y sincronizar repositorios.

## Actividades realizadas
- Instalación y configuración de Git en Ubuntu.
- Creación del archivo `estudiante.txt`.
- Inicialización de un repositorio local con `git init`.
- Registro de cambios utilizando `git add` y `git commit`.
- Configuración del repositorio remoto en GitHub.
- Sincronización mediante `git push`.

## Herramientas utilizadas
- Ubuntu Linux
- Oracle VirtualBox
- Git
- GitHub

## Archivo principal
`estudiante.txt`: contiene los datos del estudiante y la información del curso.
